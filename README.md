# EduPrime

EduPrime is a responsive educational website built using Python Flask and SQLite.

## Features

- User Login and Registration
- User Dashboard
- Courses
- Teachers
- Gallery
- Contact Form
- Admin Panel
- SQLite Database
- Responsive Design

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
